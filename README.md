# Офис Royale

Мини-казино для добровольного распределения рабочих задач, без денежных ставок.
Четыре режима: рулетка, слоты, выбор карты и кубики. Все используют криптографический случайный выбор исполнителя. Игровые символы — оформление, они не определяют вероятность. Режим равномерного распределения выбирает среди людей с наименьшим числом назначений в сохранённой истории. Отмена назначения удаляет его из счётчика. Имена считаются одинаковыми без учёта регистра.

## Запуск

Из `/workspace/example-testing-of-codex-capabilities`:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Откройте сайт через доступный в вашей среде адрес сервера. Сборка и установка зависимостей не нужны. Для публикации загрузите `index.html`, `style.css` и `app.js` на статический HTTPS-хостинг (например, GitHub Pages). Внешний шрифт необязателен: без него используется системный.

## Проверки

```sh
node --test tests/selection.test.js
```

Данные хранятся в localStorage одного браузера. Совместной синхронизации, учётных записей и защиты результатов от редактирования нет. Для общего журнала команды потребуется сервер и авторизация. Эта версия не опубликована в интернете автоматически.
