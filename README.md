# Royale Garage

Онлайн-игры для команды с оформлением GPS и автомобилей. Виртуальные фишки нельзя купить или вывести: это игровой счёт. При желании проигравшему можно назначить рабочую задачу по договорённости с участниками.

## Возможности

- Регистрация по логину и паролю, вход и выход. Новый аккаунт получает 1000 фишек. Пароли хешируются через scrypt с индивидуальной солью; сессии используют HttpOnly-cookie.
- Несколько игроков могут быть онлайн одновременно и играть в разных комнатах. Каждая партия рассчитана на **двух игроков**, у пользователя одна активная партия.
- Вызов игрока, уведомление внутри сайта, принятие/отказ/отмена. Приглашение действует ровно 5 минут; сервер отклоняет просроченные ответы.
- Ставка с каждого участника фиксируется перед игрой, списывается при принятии приглашения. Победитель получает весь банк; при ничьей ставки возвращаются. Можно играть с нулевой ставкой.
- Пятикарточный покер: каждому пять карт, один обмен от нуля до пяти карт, затем сравнение комбинаций. Это не Texas Hold’em; дополнительных ставок после раздачи нет.
- Подкидной дурак: колода 36 карт, козырь, атака, защита, подкидывание совпадающих рангов до лимита, взятие, отбой и добор. Без перевода.
- Шахматы: допустимые ходы, рокировка, взятие на проходе, превращение, шах, мат, пат и автоматические ничьи через chess.js.
- SSE передаёт изменения всем подключённым игрокам; после переподключения клиент получает актуальное состояние. Балансы, журнал фишек, сессии и партии переживают перезапуск сервера.
- Отключение браузера не завершает партию: игрок может вернуться. Сдача отдаёт банк сопернику. Лимита времени ходов нет.
- Первоначальные рулетка, слоты, выбор карты и кубики для назначения задач сохранены на `/tasks.html`. Их история остаётся локальной в браузере и не влияет на баланс аккаунта.

## Запуск

Требуется Node.js 24 или новее. В корне репозитория:

```sh
npm ci
npm test
npm start
```

Сервер слушает `0.0.0.0:3000`. Для совместной игры оба участника должны открыть **один и тот же адрес этого сервера** в своих браузерах, зарегистрироваться, затем выбрать соперника и отправить вызов. Сайт показывает присутствие игрока при открытой вкладке.

Переменные окружения:

| Переменная | Значение |
| --- | --- |
| `PORT` | Порт сервера, по умолчанию `3000` |
| `DATA_DIR` | Каталог базы, по умолчанию `./data` |
| `PUBLIC_ORIGIN` | Полный публичный origin, например `https://garage.example.com`; нужен при работе через HTTPS-прокси |
| `COOKIE_SECURE` | `1` для HTTPS-публикации: передавать сессионные cookie только по HTTPS |

Пример запуска через HTTPS-прокси:

```sh
PUBLIC_ORIGIN=https://garage.example.com COOKIE_SECURE=1 DATA_DIR=/var/lib/royale npm start
```

## Публикация и сохранение данных

Для размещения нужен хостинг Node.js 24 с **постоянным диском**, один процесс сервера и HTTPS. Настройте команду установки `npm ci`, запуска `npm start`, публичный origin и постоянный `DATA_DIR`. Прокси должен пропускать длительные SSE-соединения без буферизации. Статический GitHub Pages больше не подходит: аккаунты и общие игры требуют сервер.

База `data/royale.sqlite` и служебные WAL-файлы исключены из Git. Не удаляйте постоянный диск при обновлении. Для простой резервной копии остановите сервер и скопируйте весь каталог `DATA_DIR`, затем запустите сервер. GitHub содержит код, а не аккаунты, пароли или балансы.

У этой версии нет восстановления забытых паролей, подтверждения почты и административной панели. Ходы и выплаты проверяются сервером, карты соперника и оставшаяся колода скрыты до окончания партии. Покер и дурак показывают руки после завершения партии. Вход и регистрация ограничены по частоте; после публикации используйте HTTPS и ограничьте доступ вашей командой при необходимости.

## Проверки

`npm test` проверяет игровые правила, скрытые карты, мат и ничью, завершение партий дурака, аккаунты, истечение приглашений, ставки, однократность выплаты и восстановление после перезапуска. Серверные тесты используют временную базу и не изменяют рабочие аккаунты.
